# Utilities

Unlike the hooks in this package, these aren't tied to React's render
lifecycle - they work anywhere: inside a component, an event handler, a
plain utility module.

- [`withExecutionTiming`](/utils/withExecutionTiming) - wraps any function so every call is timed and logged
