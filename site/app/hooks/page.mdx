# Hooks

**React Diagnostic Tools** ships 10 hooks grouped into 4 categories. Pick one
below, or use the sidebar to jump straight to a hook's page - each one has a
full API reference and a live, interactive demo you can play with (open your
browser console to see the real log output).

## Render debugging

- [`useWhyRender`](/hooks/useWhyRender) - logs which props changed and caused a re-render
- [`useRenderCount`](/hooks/useRenderCount) - counts every render, regardless of cause
- [`useTraceRender`](/hooks/useTraceRender) - logs the full props on every render, changed or not
- [`useTrackedEffect`](/hooks/useTrackedEffect) - wraps `useEffect` and reports which dependency changed

## Refs

- [`usePrevious`](/hooks/usePrevious) - returns the value from the previous render
- [`useTrackedValue`](/hooks/useTrackedValue) - labels a value in DevTools and logs it on change

## Performance

- [`useMemoPerformance`](/hooks/useMemoPerformance) - analyzes whether a `useMemo` is actually worth it
- [`useExecutionTime`](/hooks/useExecutionTime) - measures a function's execution time, with a `warnIfAbove` threshold
- [`useMeasuredCallback`](/hooks/useMeasuredCallback) - a drop-in `useCallback` that logs how long it takes every time it's called

## State

- [`useStateLogger`](/hooks/useStateLogger) - a drop-in `useState` that logs every change

## Utilities

Not a hook - works anywhere, not just inside a component.

- [`withExecutionTiming`](/utils/withExecutionTiming) - wraps any function so every call is timed and logged
