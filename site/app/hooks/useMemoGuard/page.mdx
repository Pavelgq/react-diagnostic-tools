# useMemoGuard

A real, on-demand A/B benchmark for `useMemo`.

Unlike [`useMemoPerformance`](/hooks/useMemoPerformance), which infers a
recommendation from cache-hit statistics gathered passively over many
renders, `useMemoGuard` lets you trigger an actual side-by-side measurement
at any moment: how long the factory takes to run fresh, versus how long it
takes to read the value `useMemo` already has cached.

`value` behaves exactly like a plain `useMemo` - it's a drop-in replacement.
`runComparison` is meant to be wired to a button in your UI: each time it's
called, it measures both timings, logs them, and updates `lastComparison`.

This assumes `factory` is pure and side-effect-free, same as the contract
for a regular `useMemo` - `runComparison` calls it one extra time purely to
measure it.

Unlike `useMemoPerformance` and `useExecutionTime`, this hook needs no
SSR-safety handling: `runComparison` only ever runs in response to a click,
which can't happen during server rendering or the client's first render, so
`lastComparison` starts as `undefined` identically on the server and the
client.

## Usage

```tsx
import { useMemoGuard } from '@atme-lab/react-diagnostic-tools';

function ExpensiveList({ items }: { items: Item[] }) {
  const { value: sorted, runComparison, lastComparison } = useMemoGuard(
    () => [...items].sort((a, b) => a.priority - b.priority),
    [items],
    { name: 'sortItems' }
  );

  return (
    <>
      <button onClick={() => runComparison()}>Run A/B comparison</button>
      {lastComparison && (
        <p>
          Without memo: {lastComparison.withoutMemoTime.toFixed(3)}ms - With
          memo: {lastComparison.withMemoTime.toFixed(3)}ms
        </p>
      )}
      <List items={sorted} />
    </>
  );
}
```

## API

```tsx
function useMemoGuard<T>(
  factory: () => T,
  deps: React.DependencyList,
  options?: UseMemoGuardOptions
): MemoGuardResult<T>;
```

`options` (optional):

```tsx
interface UseMemoGuardOptions {
  /** Name used in the console output (default: 'useMemoGuard') */
  name?: string;
}
```

Return value:

```tsx
interface MemoGuardResult<T> {
  /** The memoized value - behaves exactly like a plain useMemo. */
  value: T;
  /** Triggers an on-demand A/B comparison. Wire this to a button. */
  runComparison: () => MemoGuardComparison;
  /** The result of the most recent runComparison() call, if any. */
  lastComparison: MemoGuardComparison | undefined;
}

interface MemoGuardComparison {
  /** Cost of calling the factory fresh, bypassing the cache (in milliseconds). */
  withoutMemoTime: number;
  /** Cost of reading the already-memoized value (in milliseconds, near-zero on a real cache hit). */
  withMemoTime: number;
  /** withoutMemoTime - withMemoTime */
  estimatedSavings: number;
}
```
