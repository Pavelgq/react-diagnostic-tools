# Security Policy

This is a small, dev-only debugging library - it has no server component
and isn't meant to run in production, which limits its realistic attack
surface. Still, if you find a security issue (e.g. something in the
supply chain, a ReDoS in a dependency, or a way this package's code could
be made to do something unexpected), please report it privately rather
than opening a public issue.

## Reporting

Use GitHub's private vulnerability reporting for this repository
(Security tab -> "Report a vulnerability"), or open a draft security
advisory. Please don't file a public issue for anything you believe is
a genuine vulnerability.

Include, if you can:

- A description of the issue and its potential impact
- Steps to reproduce, or a minimal repro
- The affected version(s)

## Response

This is maintained by a single person in their spare time, so please be
patient - there's no formal SLA, but reports will be acknowledged and
looked at as soon as reasonably possible.
